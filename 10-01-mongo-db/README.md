# Conexión a base de datos local de MongoDB

Para conectarse a una base de datos local de MongoDB, se puede utilizar la siguiente cadena de conexión:

```
mongodb://localhost:27017/DGTDB
```

Asegúrate de que el servidor de MongoDB esté en ejecución en tu máquina local antes de intentar conectarte.
